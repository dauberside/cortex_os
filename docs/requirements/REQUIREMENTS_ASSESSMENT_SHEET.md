# アセスメントシート要件定義

## 概要

利用者の生活能力・支援の必要度を評価するためのアセスメントシート機能

## 画面構成

### ルート構造

利用者詳細ページ（`/recipients/[id]`）を基本情報の上階層とし、その下にアセスメント機能を配置

- `/recipients/[id]` - 利用者基本情報（フェイスシート）
  - `/recipients/[id]/assessment` - アセスメント一覧・最新評価表示
  - `/recipients/[id]/assessment/new` - 新規アセスメント作成
  - `/recipients/[id]/assessment/[assessmentId]` - アセスメント詳細
  - `/recipients/[id]/assessment/[assessmentId]/edit` - アセスメント編集

この構造により、利用者の基本情報を確認しながらアセスメントにアクセスできる。

## データ構造（Prisma Schema）

詳細なフィールドリストは`docs/archive/引き継ぎ用.md`およびスキーマ拡張提案書（`SCHEMA_EXTENSION_PROPOSAL.md`）を参照。

### 既存のAssessmentモデル（1-5段階評価）

```prisma
model Assessment {
  id              String   @id @default(cuid())
  recipientId     String
  recipient       CareRecipient @relation(fields: [recipientId], references: [id])
  assessmentDate  DateTime @default(now()) // 評価日
  assessedBy      String?  // 評価者

  // ADL（日常生活動作）
  mobilityLevel      Int?     // 移動: 1-5 (1=自立, 5=全介助)
  mobilityNote       String?  // 移動詳細

  eatingLevel        Int?     // 食事: 1-5
  eatingNote         String?  // 食事詳細

  toiletingLevel     Int?     // 排泄: 1-5
  toiletingNote      String?  // 排泄詳細

  bathingLevel       Int?     // 入浴: 1-5
  bathingNote        String?  // 入浴詳細

  dressingLevel      Int?     // 更衣: 1-5
  dressingNote       String?  // 更衣詳細

  groomingLevel      Int?     // 整容: 1-5
  groomingNote       String?  // 整容詳細

  // コミュニケーション
  verbalCommLevel    Int?     // 言語的コミュニケーション: 1-5
  verbalCommNote     String?

  nonverbalCommLevel Int?     // 非言語的コミュニケーション: 1-5
  nonverbalCommNote  String?

  comprehensionLevel Int?     // 理解力: 1-5
  comprehensionNote  String?

  // 認知・行動
  memoryLevel        Int?     // 記憶力: 1-5
  memoryNote         String?

  judgmentLevel      Int?     // 判断力: 1-5
  judgmentNote       String?

  orientationLevel   Int?     // 見当識: 1-5
  orientationNote    String?

  behaviorIssues     String?  // 行動上の課題
  behaviorNote       String?

  // 社会性
  socialSkillLevel   Int?     // 対人関係: 1-5
  socialSkillNote    String?

  groupActivityLevel Int?     // 集団活動: 1-5
  groupActivityNote  String?

  // 作業・活動
  taskUnderstanding  Int?     // 作業理解: 1-5
  taskUnderstandingNote String?

  taskPerformance    Int?     // 作業遂行: 1-5
  taskPerformanceNote String?

  // 危険認識
  riskAwarenessLevel Int?     // 危険認識: 1-5
  riskAwarenessNote  String?

  // 口腔衛生
  oralHygieneLevel   Int?     // 口腔ケア: 1-5
  oralHygieneNote    String?

  // その他
  overallNote        String?  // 総合所見
  supportGoals       String?  // 支援目標

  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  deletedAt   DateTime?

  @@index([recipientId])
  @@index([assessmentDate])
}
```

**注**: 既存モデルの1-5段階評価と、紙シートの3段階評価（自立/ある程度できる/できない）の統合方法については、スキーマ拡張提案書で検討事項として記載。

## 評価レベルの定義

### 1-5段階評価

- **1**: 自立（見守りも不要）
- **2**: ほぼ自立（見守りが必要）
- **3**: 一部介助（部分的な支援が必要）
- **4**: 多くの介助（大部分の支援が必要）
- **5**: 全介助（全面的な支援が必要）

## 権限設定

### 閲覧権限

- MANAGER: 全利用者のアセスメント閲覧可
- LEAD: 自分の所属事業所の利用者のみ
- STAFF: 自分が担当する利用者のみ

### 作成・編集権限

- MANAGER: 全て可
- LEAD: 自分の所属事業所の利用者のみ
- STAFF: 制限（LEADの承認が必要など）

### 削除権限

- MANAGER: 全て可
- LEAD: 自分が作成したもののみ
- STAFF: 不可

## 監査ログ

以下のアクションを記録:

- アセスメント作成
- アセスメント編集（変更内容を記録）
- アセスメント削除
- アセスメント閲覧（オプション）

## バリデーション

### 必須項目

- 評価日
- 最低1つの評価項目

### 入力制限

- レベル評価: 1-5の整数
- 日付: 過去日付のみ（未来日付は警告）
- テキスト: 最大文字数制限

## 通知機能（オプション）

- アセスメント期限リマインダー（例: 6ヶ月ごと）
- 評価レベルが著しく変化した場合の通知

## 帳票出力

### PDF出力

- アセスメントシート形式のPDF
- 利用者情報 + 評価結果
- レーダーチャート含む

### CSV出力

- 複数利用者のアセスメント結果を一括出力
- 統計分析用

## 統計・分析機能（将来拡張）

- ADLレベルの推移グラフ
- 複数回のアセスメント比較
- 利用者全体の統計（事業所レベル）

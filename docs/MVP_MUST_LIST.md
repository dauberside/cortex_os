# MVP Must リスト（1ページ固定版）

**作成日**: 2026-03-02
**目的**: MVPのMust要件を1ページに固定し、開発の優先順位を明確化する
**対象**: 福祉事業所向け重度障害者支援システム

---

## 🎯 MVPの定義

福祉事業所が **法令遵守** しながら **紙帳票から移行** できる最小機能セット。
以下の4つの柱で構成される:

1. **利用者管理** - 編集・印刷・CSV（紙からの移行）
2. **ガイド記録（Do）** - 外出支援の記録と提出
3. **実績（Fact）** - サービス提供実績の自動生成
4. **監査・権限** - 変更履歴・アクセス制御

## 🎯 MVP達成の定義

以下の **5つの基準** を全て満たした状態をMVP達成とする:

1. ✅ **利用者情報を紙帳票形式で印刷できる**（フェイス/アセスメント/サポート基本情報票）
2. ⚠️ **ガイド記録をDRAFT→SUBMITTED状態で提出し、ServiceRecordが自動生成される**
3. ⚠️ **ServiceRecordを一覧・詳細で確認できる**
4. ❌ **支援記録を作成し、個別支援計画項目（planItemRefs）に紐付けられる**
5. ⚠️ **利用者データへのアクセス履歴（閲覧・編集・印刷）が記録される**

**現在の達成度**: 3/5（60%）⬆️

**補足**:
- 基準2「ガイド記録提出→実績生成」: UI実装済み、動作確認で✅になる見込み
- 基準3「ServiceRecord確認」: 既に達成済み
- 基準5「アクセス履歴記録」: 閲覧・印刷ログは一部実装済みだが、UI表示がないため未達扱い

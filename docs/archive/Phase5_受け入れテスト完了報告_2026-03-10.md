## ビルド検証

### TypeScript コンパイルエラー修正

受け入れテスト実施後、月次締め画面（`/attendance/monthly-closing`）のTypeScriptコンパイルエラーを修正しました。

**修正内容**:

1. **listHistory → list に修正** (3箇所)
   - tRPCルーター名が `list` なのに、フロントエンドで `listHistory` を呼んでいた
   - `src/app/attendance/monthly-closing/page.tsx:69, 84, 93`

2. **CSV export URL format 修正**
   - tRPCクエリパラメータに `json` ラッパーが必要だった
   ```typescript
   // Before
   JSON.stringify({unitId, yearMonth})

   // After
   JSON.stringify({json: {unitId, yearMonth}})
   ```

3. **closingStatus プロパティ型修正**
   - `closingStatus?.status === "CLOSED"` → `closingStatus?.isClosed === true`
   - `closingStatus.closedAt` → `closingStatus.closing.closedAt`
   - `closingStatus.closedByUser` → `closingStatus.closing.closedByUser`

4. **summary プロパティ名修正**
   - `summary.staffCount` → `summary.totalStaff`
   - `summary.totalDays` → `summary.totalRecords`

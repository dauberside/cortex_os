ただ、GitHub上で新規リポジトリを直接作成する操作はこちらでは実行できないので、進め方としては

ローカルで project-docs-template を先に作る → GitHub に新規 repo を作って push

が最短です。

進め方はこれで十分です。
	1.	project-docs-template をローカルに作成
	2.	必要ファイルをテンプレート化して配置
	3.	README.md と scripts/init-docs.sh を作成
	4.	GitHub に空の repo を作成して push

特に今やるべきなのは、GitHub repo 作成より先に テンプレートの中身を固めること です。
ここが決まっていれば、GitHub 側は最後に載せるだけで済みます。

おすすめの初期スコープはこの範囲です。
	•	.github/pull_request_template.md
	•	docs/AI_STANDARD_INSTRUCTIONS.md
	•	docs/README.md
	•	docs/requirements/
	•	docs/design/
	•	docs/implementation/
	•	docs/status/
	•	docs/testing/
	•	docs/operations/
	•	docs/troubleshooting/
	•	docs/archive/
	•	templates/ 配下の各種テンプレ
	•	scripts/init-docs.sh
	•	ルートの README.md

結論:
今は GitHub repo 作成より、テンプレート本体の雛形を先に作るべきです。
そのあと GitHub に project-docs-template を作って push する流れがいちばんきれいです。

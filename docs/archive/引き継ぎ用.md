### outingDone の書き込み経路（2026-03-18 整備済み）

`dailyLog.upsertEntry` で `outingDestination` 非空なら `outingDone=true`、空なら `false` を自動保存。

```ts
const outingDone = !!(data.outingDestination && data.outingDestination.trim() !== "");
```

`outingDone` カラムは DB に既存（`schema.prisma` の定義が漏れていたのみ、今回追加済み）。
